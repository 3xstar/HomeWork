1. Что такое хранимая процедура?
2. Для чего нужны параметры процедуры?
3. Зачем в CreateDeal используется OUTPUT?
4. Для чего используется IF NOT EXISTS?
5. Что делает TRY...CATCH?
6. Для чего нужен THROW?
7. Чем SELECT внутри процедуры отличается от OUTPUT?
8. Почему проверку входных данных удобно выполнять внутри процедуры?
9. Может ли процедура изменять данные в таблицах?
10. В чём отличие процедуры от VIEW?

Ответы:
1. Процедура — это сохранённый именованный блок SQL-кода с параметрами и логикой, который можно вызывать по имени.
2. Параметры нужны, чтобы передавать входные значения и делать процедуру универсальной.
3. OUTPUT нужен, чтобы вернуть из процедуры значение наружу — например, id созданной сделки.
4. IF NOT EXISTS проверяет, что запись существует, и позволяет выбросить ошибку, если её нет.
5. TRY...CATCH перехватывает ошибку внутри процедуры и не даёт выполнению упасть полностью.
6. THROW вручную генерирует ошибку с номером и сообщением, например при некорректных данных.
7. SELECT возвращает набор строк, а OUTPUT — одно значение через параметр.
8. Потому что проверка внутри процедуры не пускает некорректные данные в таблицы при любом вызове.
9. Да, процедура может вставлять, обновлять и удалять данные — например, CreateDeal вставляет сделку.
10. Процедура — исполняемый код с параметрами и логикой, а VIEW — просто сохранённый SELECT без логики выполнения.
