1. Чем оконная функция отличается от обычной агрегатной функции?
2. Для чего используется OVER()?
3. Что делает PARTITION BY?
4. Чем ROW_NUMBER() отличается от RANK()?
5. Чем RANK() отличается от DENSE_RANK()?
6. Для чего используется LAG()?
7. Для чего используется LEAD()?
8. Почему оконная функция позволяет сохранить исходные строки?
9. Как построить накопительную сумму?
10. Почему удобно сначала выполнить агрегацию в CTE, а затем применить оконную функцию?

Ответы:
1. Оконная не схлопывает строки, агрегатная — схлопывает в одну.
2. Для задания окна: по каким строкам и в каком порядке считать функцию.
3. Делит строки на группы, окно считается отдельно внутри каждой группы.
4. ROW_NUMBER() даёт уникальные номера подряд, а RANK() — одинаковые при равных значениях, с пропусками.
5. RANK() при равенстве даёт одинаковый номер и пропускает следующие, а DENSE_RANK() — одинаковый номер без пропусков.
6. Для получения значения из предыдущей строки.
7. Для получения значения из следующей строки.
8. Потому что вычисляется поверх исходного набора строк, не убирая их.
9. Через SUM() OVER (PARTITION BY ... ORDER BY ...).
10. Чтобы сначала получить агрегаты, а потом на их основе строить рейтинги и оконные вычисления.
