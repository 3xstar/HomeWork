1. Что такое пользовательская функция?
2. Чем scalar-функция отличается от table-valued function?
3. Что возвращает scalar-функция?
4. Что возвращает inline table-valued function?
5. Где можно использовать пользовательскую функцию?
6. Чем функция отличается от хранимой процедуры?
7. Чем функция отличается от `VIEW`?
8. Зачем функции передаются параметры?
9. Почему функция должна возвращать определённый тип данных?
10. В каких ситуациях использование функции может упростить SQL-запрос?

Ответы:
1. Функция — это сохранённый именованный блок SQL-кода, который принимает параметры, выполняет вычисления и обязательно возвращает результат.
2. Скалярная функция возвращает строго одно значение, а табличная функция возвращает целый набор строк (таблицу).
3. Скалярная функция возвращает одно конкретное значение определённого типа, например число или строку. 
4. Inline табличная функция возвращает результат выполнения одного конкретного запроса SELECT в виде таблицы.
5. Скалярную функцию можно использовать в SELECT, WHERE и ORDER BY, а табличную — в секции FROM вместо обычной таблицы.
6. Функция обязательно возвращает значение и вызывается внутри запросов, а процедура вызывается через EXEC и может менять данные в таблицах.
7. Функция принимает параметры и может содержать логику вычислений, а VIEW — это просто сохранённый SELECT без параметров.
8. Параметры нужны, чтобы передавать входные значения и делать функцию универсальной для разных данных.
9. Чтобы SQL Server мог проверить совместимость данных в запросе и избежать ошибок приведения типов при выполнении.
10. Когда нужно избавиться от дублирования сложного кода (например, формул или CASE) и повторно использовать его в разных запросах.
