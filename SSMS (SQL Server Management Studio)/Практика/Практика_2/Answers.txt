Ответы:
1. Подзапрос — это запрос внутри другого запроса.
2. В WHERE, FROM, SELECT, HAVING и других частях запроса.
3. Внешний — основной запрос, внутренний — подзапрос внутри него.
4. Одно значение (одна строка и один столбец).
5. Для проверки, входит ли значение в набор значений из подзапроса.
6. IN сравнивает с набором значений, а = — только с одним значением.
7. Для проверки, возвращает ли подзапрос хотя бы одну строку.
8. Потому что важно только наличие строк, а не сами данные.
9. Проверяет, что подзапрос не возвращает ни одной строки.
10. Подзапрос, который зависит от внешнего запроса.
11. Коррелированный выполняется для каждой строки внешнего запроса, обычный — один раз.
12. Чтобы различать столбцы внешней и внутренней таблицы.
13. Да, можно.
14. Когда нужно сравнить значение со средним по таблице.
15. Когда нужно проверить наличие связанных данных без вывода самих данных.
16. Когда внутри подзапроса используется столбец из внешнего запроса.
