1. Для чего используется `DECLARE`?
2. Для чего используется `SET`?
3. Как получить значение из таблицы в переменную?
4. Для чего используются переменные?
5. Чем `IF` отличается от `CASE`?
6. Для чего используется `ELSE IF`?
7. Как проверить несколько условий?
8. Что делает `AND`?
9. Что делает `OR`?
10. Почему порядок условий в `CASE` имеет значение?
11. Что произойдёт, если ни одно условие `WHEN` не выполнится?
12. Для чего используется `ELSE` в `CASE`?
13. Что такое арифметическое выражение?
14. Почему результат `10 / 3` может быть равен `3`?
15. Для чего используется `DECIMAL`?
16. Для чего нужны `CAST()` и `CONVERT()`?

Ответы:
1. DECLARE — объявляет переменную.
2. SET — изменяет значение переменной.
3. С помощью SELECT @Переменная = Столбец FROM Таблица WHERE ...
4. Для хранения промежуточных значений и упрощения логики.
5. IF выполняет блок кода, а CASE возвращает значение (используется в SELECT).
6. ELSE IF — для проверки дополнительных условий, если предыдущее не выполнено.
7. С помощью AND, OR или комбинации IF ... ELSE IF ... ELSE.
8. AND — все условия должны быть истинными.
9. OR — хотя бы одно условие должно быть истинным.
10. Потому что проверка идет по порядку, и сработает только первое подходящее условие.
11. Вернется NULL (если нет ELSE).
12. ELSE — задает значение по умолчанию, если ни одно условие не подошло.
13. Выражение, состоящее из чисел, операторов (+, -, *, /) и переменных.
14. Потому что оба числа целые, и SQL делает целочисленное деление.
15. Для хранения дробных чисел с фиксированной точностью.
16. Для преобразования одного типа данных в другой (например, в DECIMAL для дробного результата).
